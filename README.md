# PERFUME

مشروع متجر عطور تعليمي مبني باستخدام Django. المتجر يدعم العربية والإنجليزية، سلة تسوق، وطلبات تجريبية من دون تحصيل أموال.

## التشغيل

```bash
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

أنشئ مديرًا لأول مرة باستخدام `python manage.py createsuperuser`، ثم سجّل الدخول وافتح `/dashboard/` لإدارة المتجر.

## لوحة إدارة المتجر وREST API

تستخدم لوحة المدير واجهات REST لحفظ التغييرات. من لوحة `/dashboard/` يمكن إضافة العطور وتعديل الاسم والوصف بالعربية والإنجليزية، والسعر والصورة والمخزون وحالة العرض. كما يمكن تغيير حالة الطلبات وتعديل نصوص الواجهة الرئيسية وقسم «قصتنا» باللغتين.

- `GET /api/products/`: عرض العطور المتاحة. ويمكن للمدير إنشاء العطور أو تعديلها أو حذفها.
- `/api/orders/`: للمدير لعرض الطلبات وتغيير حالتها.
- `/api/site-content/`: قراءة نصوص الصفحة الرئيسية؛ التعديل للمدير.
- `POST /api/assistant/`: سؤال مساعد المتجر باللغة العربية أو الإنجليزية.
- `/api/`: فهرس الواجهات، و`/api-auth/login/` لتسجيل الدخول إلى متصفح DRF.

تتطلب عمليات التعديل جلسة دخول لحساب مدير، وبقية الزوار يستطيعون قراءة العطور واستخدام مساعد المتجر.

## مساعد المتجر

المساعد محلي داخل المشروع. يستخدم بيانات العطور والأسعار والمخزون وبعض قواعد الكلمات المفتاحية للرد على أسئلة المنتجات والتوصيل والطلبات التجريبية. لا يتصل بمزود ذكاء اصطناعي خارجي، ولا يجيب عن أسئلة عامة خارج معلومات المتجر.
